# Jogo de Adivinhação de Palavras
Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I.
## Integrantes
-Johann Barros Brito
## Como jogar
Digite uma letra e clique em Tentar. O objetivo é descobrir a palavra antes de acabar as
tentativas.
## Tecnologias
- HTML5
- CSS3
- JavaScript

Web I — Atividade de Encerramento — Jogo de Adivinhação de Palavras

## Funcionalidades
- Palavra aleatória
- Controle de tentativas
- Letras utilizadas
- Reinício da partida
